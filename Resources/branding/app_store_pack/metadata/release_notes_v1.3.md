# EventViewer 1.3

- Add a selectable gallery with six sample widget previews and optional rounded Cards presentation.
- Add eight graph forms for scoped buffered events: grid, sparkline, gauges, numeric, history bars, stacked severity, severity ring and paired error/warning area.
- Add optional adaptive/fixed event-rate graph domains, separate from warning thresholds.
- Preserve Classic custom HUDs and built-in widgets; retain legacy saved definitions and token layouts.
- Protect unreadable widget archives from accidental edits and overwrites.

Gallery images contain sample data. New event Cards summarize the retained event buffer; they do not establish complete or authoritative OSLog coverage.
