# EventViewer v1.4 for macOS

## What's New in v1.4

### 🎨 Low Effort Suite Cross-App Theme & Persistent Dock Icon Sync
- **1-Click Cross-App Theme Synchronization**: Detect installed Low Effort tools (`PerfMon`, `VolMan`) directly in **Settings** and synchronize themes, custom accent hex colors, monogram role (`App Initials`, `LE`, or custom), and widget HUD opacity/blur across individual tools or the entire suite (`Match All`).
- **Persistent `.app` Bundle Dock Icon Sync**: Synchronizing or changing themes updates both the live runtime Dock tile and the `.app` bundle's on-disk `AppIcon.icns`, so custom themed Dock icons (`EV`, `PM`, `VM`, or `LE`) remain identical even when apps are closed or quit.
- **Unified Studio Theme Palette & Responsive Controls**: Added `Vivid Purple` and unified theme IDs across all Low Effort apps, plus adaptive multi-line `FlowLayout` wrapping across Settings views so controls never clip or overflow in narrow windows.

### 📊 Visual Widget Gallery & Eight Event Graph Styles
- Includes the 6-preview widget gallery, optional rounded **Cards** presentation, and 8 graph styles (`Win11 Grid`, `Sparkline`, `Gauges`, `Large Readout`, `History Bars`, `Stacked Severity`, `Severity Ring`, and `Error / Warning Area`).
